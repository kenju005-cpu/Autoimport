Activar la nube

La V18 funciona sin nube para pruebas. Para producción, conecta un proyecto Supabase y aplica estas cuatro piezas.

1. Crear proyecto Supabase

Crea el proyecto y copia Project URL y la Publishable key. La clave secreta nunca debe ir en la app.

2. Crear tablas y permisos

Ejecuta el archivo supabase/schema.sql en SQL Editor. Después crea en Storage un bucket privado llamado order-documents.

3. Configurar el navegador

Copia config.example.js como config.js y rellena:

supabaseUrl: "https://....supabase.co"
supabasePublishableKey: "sb_publishable_..."

4. Crear tu usuario administrador

Crea tu usuario en Authentication y ejecuta la última instrucción comentada de schema.sql sustituyendo TU_EMAIL. Los clientes se crean con rol client por defecto.
